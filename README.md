## Architecture Principles

- **Clean Architecture** — domain, application, infrastructure, and API layers kept independent
- **SOLID & DDD** — designing around the domain, not the database schema
- **Repository Pattern & DI** — testable, swappable data access
- **Event-Driven Architecture** — async workflows for real-time and collaboration features
- **TDD** — xUnit, NUnit, MSTest, Moq/NSubstitute, and Playwright for end-to-end coverage
